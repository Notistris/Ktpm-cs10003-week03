# TC-SUB-001: Subtract two positive integers successfully

## Requirement ID
FR-SUB-01

## Module / Test type / Technique
Subtraction / Functional / Equivalence Partitioning

## Preconditions
- The Basic Calculator page is open
- Build `Prototype` is selected
- The calculator is ready for input

## Test data
| Field | Value |
|---|---|
| First number | `25` |
| Second number | `10` |
| Operation | `Subtract` |
| Integers only | Unchecked |

## Test steps
1. Enter `25` in **First number**
2. Enter `10` in **Second number**
3. Select `Subtract` from **Operation**
4. Leave **Integers only** unchecked
5. Click **Calculate**

## Expected result
The **Answer** field displays `15` and no error message is shown.

## Status / Related bugs
Not Run / None
