# TC-SUB-007: Subtract two decimal numbers

## Requirement ID
FR-SUB-01

## Module / Test type / Technique
Subtraction / Functional / Equivalence Partitioning

## Preconditions
- The Basic Calculator page is open
- Build `Prototype` is selected
- The calculator is ready for input

## Test data
| Field | Value |
|---|---|
| First number | `10.75` |
| Second number | `2.25` |
| Operation | `Subtract` |
| Integers only | Unchecked |

## Test steps
1. Enter `10.75` in **First number**
2. Enter `2.25` in **Second number**
3. Select `Subtract` from **Operation**
4. Leave **Integers only** unchecked
5. Click **Calculate**

## Expected result
The **Answer** field displays `8.5` and no error message is shown.

## Status / Related bugs
Not Run / None
