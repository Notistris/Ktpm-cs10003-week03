# TC-CALC-CONCAT-002: Nối hai chuỗi ký tự số (Numeric Strings)

## Requirement ID
FR-CALC-CONCAT

## Module / Test type / Technique
Calculator / Functional / Equivalence Partitioning

## Preconditions
- User đang ở trang máy tính cơ bản.

## Test data
| Field | Value |
| --- | --- |
| Input 1 | 123 |
| Input 2 | 456 |
| Operation | Concatenate |

## Test steps
1. Nhập giá trị vào Input 1
2. Nhập giá trị vào Input 2
3. Chọn phép tính (Operation) là "Concatenate"
4. Bấm nút tính toán

## Expected result
Hệ thống hiển thị kết quả là chuỗi "123456" (không phải là phép cộng toán học 579).
