# TC_ADD_07: Số nguyên dương cộng số nguyên âm (kết quả âm)

## Requirement ID
FR-CALC-ADD-01

## Module / Test type / Technique
Calculator - Add / Functional / Equivalence Partitioning

## Preconditions
- Người dùng đã truy cập trang web Basic Calculator (https://testsheepnz.github.io/BasicCalculator.html)
- Build được chọn: Prototype (Build 0)

## Test data
| First number | 10 |
| Second number | -45 |
| Operation | Add |
| Integers only | Unchecked |

## Test steps
1. Mở trang Basic Calculator
2. Nhập 10 vào ô First number
3. Nhập -45 vào ô Second number
4. Chọn phép tính Add từ dropdown Operation
5. Bấm nút Calculate

## Expected result
Ô Answer hiển thị kết quả -35. Không có thông báo lỗi xuất hiện.
